# Lung-Cancer-Dashboard
A Data Science and Technology (DST) project featuring a dashboard for analyzing lung cancer risk factors, patient symptoms, and cancer outcomes using interactive visualizations and KPIs.
# Overview

This DST project presents a dashboard for analyzing lung cancer risk factors, patient symptoms, and cancer outcomes using data visualizations and key performance indicators (KPIs).

# Dashboard Features

Outcome analysis by age group

Cancer outcome by gender

Lifestyle risk factor analysis

Risk factor comparison

Key performance indicators (KPIs)

# Tools Used

Microsoft Power BI

Data Visualization
